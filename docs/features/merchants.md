# Merchants

A merchant is the outside party in an income or expense transaction, such as an employer or shop. A merchant has a required label of up to 100 characters, trimmed before saving.

| Transaction | Merchant |
| --- | --- |
| Income | Required: the payer |
| Expense | Required: the payee |
| Transfer | Not allowed |

## Create and find

Create a merchant with **+** beside *Merchants*, or enter a new name in the transaction form. Inline creation happens with the transaction. The merchant field matches labels without case sensitivity and returns up to 20 suggestions by default.

## Delete

Deletion is soft, so past transactions retain their history. A filter for a deleted merchant is removed and reported.
